结构与热设计

壳体、75.0 mm 基线、RV1126B 散热路径。

演示工具（烧录、现场页、标定）为英文界面。

两面

热量在哪里

散热路径：RV1126B，相机面中央。双 ISP、立体与 NPU。相机、eMMC 与 VS6621 不走这条路径。

区域PCB 上壳体里
SoC 顶盖 相机面大方块，两眼之间 主冷却点。软导热垫或导热泥贴到金属壁、均热板或小散热器。
SoC 过孔区 连接器面中央，BGA 下方 次冷却点。绝缘间隙垫把该铜区导入同一金属体积。
电源管理 / 电源 连接器面中央偏左的深色块 空气或轻垫。USB-C 与 PH 保持畅通。
相机 两端黑色镜筒 光学避让区。支撑 PCB，切勿夹紧或扭转模组。
Wi-Fi / 天线 右侧方块与金色射频焊盘 天线前方用塑料或空气。这里放金属会毁掉距离，也带不走 SoC 热量。

芯片工作温度 35–45 °C。内核保护 115 °C（cpu-thermal / soc-crit）。被动散热按静止 25 °C 空气下该区间上沿设计。NPU 关闭时在下沿。

散热是壳体的一部分

夹持相机的金属，同时把 RV1126B 的热带走。

1. 贴住顶盖 在 RV1126B 顶盖上放 1–2 mm 硅胶间隙垫（电绝缘，导热 ≥ 3 W/m·K），压缩 10–30 %，贴到平整铝或钢壁。该壁可以是壳体后盖，或粘在后盖上的小均热板。
2. 用过孔区 连接器面过孔区再贴第二块垫，导入同一金属。
3. 一个刚性体积 立体基线就是这块 PCB。壳体托住板子，而不是夹相机镜筒。在绿色外形下做凸台或凹槽；相机在开孔中悬浮。
4. 留下维护面 USB-C、BOOT、RST 与 PH 保持可及，或用短线引出。Maskrom：按住 BOOT，点按 RST。

质量与空气表面积

被动。顶盖垫贴到能看见室温空气的铝件。不要风扇。

双 ISP 与立体约 2.0 W，NPU 关闭。NPU 开启约 3.0 W。室温 25 °C。设计芯片温度：关闭 42 °C，开启 45 °C。垫约 1.5 °C/W。静止铝件在自由空气中约 12 W/m²·K（含辐射）。

A = Psink / (h · (Tdie − 25 − Psink · 1.5))。约 0.4 W 留在板上，所以散热器看到关闭 1.6 W、开启 2.6 W。

装配顺序

1

电路板

  1. 拿绿色外形，不要拿相机镜筒，也不要按 SoC 顶盖。
  2. 两颗模组摆正。基线就是这块 PCB。
  3. 连接器面保持干净。过孔区上的助焊剂或油脂会挡住导热垫。
2

导热件

  1. 顶盖垫只贴 RV1126B 方块。
  2. 背面垫只裁到过孔区。避开 USB-C、PH、RST、BOOT 与 UART 焊盘。
  3. 若能防止装板时滑动，先把垫贴到金属上。
3

壳体

  1. 把板放到凸台上。相机最后进入开孔，不要侧向受力。
  2. 合盖，让 SoC 垫压缩。确认 BOOT 与 RST 仍能按下。
  3. 引出 USB-C 与 PH，不要把板从导热垫上拉开。
4

验证路径

  1. USB-C 供电。等立体与 ISP 起来后，用 python tools/cv_ego_page.py 打开页面（英文界面）。
  2. 深度起来后片上传感器：35–45 °C（35000–45000）。NPU 关闭在下沿；NPU 开启接近 45 °C。
  3. 超过 45 °C：顶盖垫没贴上，或齿没有空气。

避让区

部位原因
相机镜筒光轴与立体基线。这里夹紧会偏移深度，也可能压裂模组。
microSD取卡。SoC 垫不要压到卡槽。
BOOT / RST / RX / TXMaskrom 与调试串口。
PH电池线。在壳体内做应力释放，不要拉在连接器上。
右侧射频方块Wi-Fi / 蓝牙。这里的金属或石墨片是天线屏蔽，不是散热器。
板弯曲外形就是立体杆。一颗拧歪 PCB 的螺丝就是标定失败。

读取 SoC 温度

已有 ADB 的板上，芯片传感器就是热区：

adb shell cat /sys/class/thermal/thermal_zone0/temp

毫摄氏度。40000 是 40 °C。工作区间 35000–45000。临界保护 115000（115 °C）。该区跟随 cpu-thermal。
