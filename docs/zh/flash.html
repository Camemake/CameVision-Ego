烧录

演示工具（烧录、现场页、标定）为英文界面。

USB

Maskrom

  1. 接上 USB-C 并给板子供电。
  2. 安装 USB 驱动（Windows：host/DriverAssitant_v5.14。Linux：host/linux/99-camevision-rockusb.rules）。
  3. 按住 BOOT，点按 RESET，继续按住 BOOT。
  4. 端口为 Maskrom 2207:110c 或 Loader。复位后变为 ADB 2207:0006。
镜像

写入

写入 loader、env、idblock、U-Boot、所选型号的 boot FIT、userdata、oem、rootfs，再通过 ADB 写入对应 overlay。

python tools/cv_ego_flash.py --prebuilt --package camevision-ego
python tools/cv_ego_flash.py --prebuilt --package camevision-ego-am

SC233HGS 重建（Wi-Fi + RV-3028 DTB）：

python tools/cv_ego_flash.py --rebuild --package camevision-ego

板子启动后松开 BOOT。商城传感器：SC233HGS、OG02C10、MIRA220、AR0235（彩色 / 黑白）、OX05B1S、开眸 GS2.3。本仓库 Maskrom 包目前为 SC233HGS 与 AM / MIRA220。

ADB

打开

python tools/cv_ego_page.py

转发板上立体页与 IMU 抬头显示，并打开浏览器。命令行与现场页为英文。

python tools/cv_ego_autostart.py --install
python tools/cv_ego_diag.py

分区表

先用 upgrade_tool db 写一次 1 GB DDR loader，再用 wl 写各 LBA。Overlay 不是分区。

LBA镜像作用
loader（db）rv1126b_spl_loader_k4a8g.bin适配 1 GB DDR 的 SPL
0x0env.imgU-Boot 环境
0x40idblock.imgidblock
0x440uboot.imgU-Boot
0x2440camevision_boot_ego.img 或 camevision_boot_ego_am.img内核 + DTB FIT，6.1.141-rt52 — SC233HGS 或 AM / MIRA220
0x7C40userdata.img骨架，再写 overlay
0x207C40oem_noko.imgrkaiq、IQ 二进制、oem 库
0x607C40rootfs_bootstable.img根文件系统
host/upgrade_tool.exe db rv1126b_spl_loader_k4a8g.bin
host/upgrade_tool.exe wl 0x0       env.img
host/upgrade_tool.exe wl 0x40      idblock.img
host/upgrade_tool.exe wl 0x440     uboot.img
host/upgrade_tool.exe wl 0x2440    camevision_boot_ego.img
host/upgrade_tool.exe wl 0x7C40    userdata.img
host/upgrade_tool.exe wl 0x207C40  oem_noko.img
host/upgrade_tool.exe wl 0x607C40  rootfs_bootstable.img
host/upgrade_tool.exe rd
python tools/cv_ego_overlay_deploy.py

镜像位置

两套 Maskrom 包分开。SC233HGS 在 restore/release-0.2-20260902/（SENSOR=SC233HGS，boot camevision_boot_ego.img）。AM / MIRA220 在 restore/release-2.0-am-mira220-20261009/（SENSOR=MIRA220，boot camevision_boot_ego_am.img）。请用 Git LFS 克隆，以便下载大镜像。冻结的 SC233HGS 设备树：device-tree/rv1126b-camevision-ego-sc233hgs.dts。AM DTS：device-tree/rv1126b-camevision-ego.dts。

Boot FIT 源：device-tree/rv1126b-camevision-ego.dts。Overlay 源：restore/release-0.2-20260902/overlay/ 以及 tools/ 下的副本。

Overlay

ADB 起来之后，产品就是 overlay。板子已经烧过：跳过 Maskrom，对该传感器运行 deploy。

python tools/cv_ego_overlay_deploy.py
python tools/cv_ego_overlay_deploy_am.py
