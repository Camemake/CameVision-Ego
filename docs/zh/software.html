驱动

Boot FIT 中的内核为 6.1.141-rt52。树内节点来自 DTB。树外模块在 overlay 中，由启动脚本 insmod。

设备树

板级源：device-tree/rv1126b-camevision-ego.dts。包含 rv1126b.dtsi。型号字符串 CameVision Ego，兼容 camemake,camevision-ego。

Boot FIT 携带编译后的 DTB。改 DTS 后需重建并写入 boot 分区。

节点状态

命令行

python tools/cv_ego_flash.py --prebuilt

tools/cv_ego_flash.py → tools/cv_ego_wifi_full_flash.py。先 upgrade_tool db 写一次 1 GB DDR loader，再 wl 各 LBA，rd，然后通过 ADB 写 overlay。

host/upgrade_tool.exe db restore/known-good-20260819-camera-adb/rv1126b_spl_loader_k4a8g.bin
host/upgrade_tool.exe wl 0x0    env.img
host/upgrade_tool.exe wl 0x40   idblock.img
host/upgrade_tool.exe wl 0x440  uboot.img
host/upgrade_tool.exe wl 0x2440 camevision_boot_ego.img
host/upgrade_tool.exe wl 0x7C40 userdata.img
host/upgrade_tool.exe wl 0x207C40 oem_noko.img
host/upgrade_tool.exe wl 0x607C40 rootfs_bootstable.img
host/upgrade_tool.exe rd
python tools/cv_ego_overlay_deploy.py

只重建 boot FIT

python tools/cv_ego_flash.py --rebuild 运行 DTB 补丁与 tools/cv_pack_release02.py，再写同样分区。Boot 镜像：camevision_boot_ego.img（FIT，11 MiB / 0x5800 扇区）。

只更新用户态

分区不动。文件在 tools/，然后 python tools/cv_ego_overlay_deploy.py。

启动链

  1. S11hwclock：RV-3028 → 系统时钟。
  2. S99ego-stereo：等待后启动立体脚本。
  3. tools/camevision-stereo.sh：kmpp、Wi-Fi、rkaiq 3A、IMU 抬头显示，然后 ego_stereo.py。
  4. 电脑 tools/cv_ego_page.py：adb forward 8081 与 8083，打开浏览器（英文界面）。
