Camera pipe in the DTB: sensor → D-PHY → CSI-2 → CIF → ISP → VPSS. Wi-Fi modules are built for this rt52 kernel; they load from /userdata/swt6621-rt52. Firmware blobs are /userdata/swt6621_fw (Seekwave / SWT6621S NV).

From the offline tool

  1. Images (same names) in restore/updates/current/, or a zip via GitHub update / Package file.
  2. USB / Maskrom: hold BOOT, tap RESET.
  3. Select the package · Install.
  4. Release BOOT when the write finishes. Overlay is pushed over ADB.

From the command line

python tools/cv_ego_flash.py --prebuilt

tools/cv_ego_flash.py → tools/cv_ego_wifi_full_flash.py. upgrade_tool db the 1 GB DDR loader once, then wl each LBA, rd, overlay over ADB.

host/upgrade_tool.exe db restore/known-good-20260819-camera-adb/rv1126b_spl_loader_k4a8g.bin
host/upgrade_tool.exe wl 0x0    env.img
host/upgrade_tool.exe wl 0x40   idblock.img
host/upgrade_tool.exe wl 0x440  uboot.img
host/upgrade_tool.exe wl 0x2440 camevision_boot_ego.img
host/upgrade_tool.exe wl 0x7C40 userdata.img
host/upgrade_tool.exe wl 0x207C40 oem_noko.img
host/upgrade_tool.exe wl 0x607C40 rootfs_bootstable.img
host/upgrade_tool.exe rd
python tools/cv_ego_overlay_deploy.py

Rebuild only the boot FIT

python tools/cv_ego_flash.py --rebuild runs the DTB patch and tools/cv_pack_release02.py, then the same write. Boot image: camevision_boot_ego.img (FIT, 11 MiB / 0x5800 sectors).

Userspace only

Leave the partitions. Files under tools/, then python tools/cv_ego_overlay_deploy.py.

Boot chain

  1. S11hwclock: RV-3028 → system clock.
  2. S99ego-stereo: waits, then starts the stereo script.
  3. tools/camevision-stereo.sh: kmpp, Wi-Fi, rkaiq 3A, IMU HUD, then ego_stereo.py.
  4. PC tools/cv_ego_page.py: adb forward 8081 and 8083, opens the browser.
