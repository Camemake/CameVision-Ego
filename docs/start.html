USB

Maskrom

  1. Connect USB-C and power the board.
  2. Install the USB driver (Windows: host/DriverAssitant_v5.14. Linux: host/linux/99-camevision-rockusb.rules).
  3. Hold BOOT, tap RESET, keep BOOT held.
Package

Install

SC233HGS or AM / MIRA220 Maskrom kits in this tree:

python tools/cv_ego_flash.py --prebuilt --package camevision-ego
python tools/cv_ego_flash.py --prebuilt --package camevision-ego-am

The package writes loader, env, idblock, U-Boot, boot, userdata, oem, rootfs, and the overlay. Release BOOT when the board starts. Partition map: Flash.

ADB

Open

python tools/cv_ego_page.py
python tools/cv_ego_diag.py

cv_ego_page.py forwards the on-board stereo page and IMU HUD to the host, then opens a browser. cv_ego_diag.py dumps identity, I2C, IMU, video nodes and dmesg.
