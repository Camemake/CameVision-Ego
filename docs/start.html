Offline installer

Get started

Unzip the folder or clone the repository. Open the Camemake installer. Same path on Windows and Linux, on an empty board or a board that already has images. Flash starts from Maskrom.

Open the tool

Windows: double-click CameVision-Ego.

Linux: open CameVision-Ego (or the desktop entry).

The Camemake window installs the packs that ship in this folder: Python, ADB, the flash tool, and USB access. The offline tool then opens at http://127.0.0.1:8765/tool.html.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Click Install USB driver.
  3. Hold BOOT, tap RESET, keep BOOT held.
Package

Install

  1. Select SC233HGS or AM / MIRA220, or load a GitHub update / a zip file.
  2. Click Install.
  3. Release BOOT when the board starts.

The package writes loader, env, idblock, U-Boot, boot, userdata, oem, rootfs, and the overlay.

GitHub update pulls the latest images from Camemake/CameVision-Ego. Package file loads a zip from disk. Both land in the same package list, then Install writes them.

ADB

Open

  1. Click Open for http://127.0.0.1:8081/.
  2. Click Extended diagnostics for a full board dump in the log: identity, memory, NPU, storage, Wi-Fi, I2C, IMU, video nodes, services, RTC, power, dmesg.
