Get started

Stereo matching, depth, calibration and the live page run on the CameVision EGO. The PC deploys the overlay over USB and opens a browser.

First connection

  1. Power the CameVision EGO and connect USB-C.
  2. Clone Camemake/CameVision-Ego.
  3. Run:
python tools/cv_ego_stereo_start.py
python tools/cv_ego_autostart.py --install

Then open http://127.0.0.1:8081/.

CommandUse
python tools/cv_ego_stereo_start.pyFirst-time or full overlay push
python tools/cv_ego_autostart.py --installAlways-on plug-in helper (once per PC)
python tools/cv_ego_page.pyForwards only, then open the page
restore/release-1-20260824/restore-release1.ps1Same as the two Python commands above

USB port forwards live on the PC and drop on unplug. That is why the helper exists. The stereo process already starts on the camera at boot (S99ego-stereo → /userdata/camevision-stereo.sh).

Live routes

URLContent
/Stereo live page (CAM1 left, CAM0 right, depth)
/calCheckerboard calibration
/ov0 /ov1Colour MJPEG, CAM0 / CAM1
/depth /xyzDepth heatmap
/imuIMU HUD (also port 8083)

Do not invert the depth CSS (scale(-1,-1) is the correct view). Do not swap the eye order in software.

Release 1

Path: restore/release-1-20260824. This is the software overlay to keep. It does not reflash boot, rootfs or oem. Python wheels stay on the camera at /userdata/pylib.

  • Dual colour ISP (AWB / CCM / gamma). Auto-exposure reattaches if a grab restart drops it
  • Both eyes triggered together at 12.5 fps, aligned to 50 Hz lighting
  • Exposure locked on 20 ms steps
  • On-board depth, 640×400, jet heatmap
  • Calibration page and IMU HUD left running

Keep USB as the CameVision EGO developer gadget. Do not flash a non-CameVision image onto the board.
