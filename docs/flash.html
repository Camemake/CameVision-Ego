Maskrom · empty board or already flashed

Flash

Hold BOOT, tap RESET, write every partition, then the overlay. USB stays ADB. Same sequence as the offline tool.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Install the USB driver (Windows: host/DriverAssitant_v5.14. Linux: host/linux/99-camevision-rockusb.rules).
  3. Hold BOOT, tap RESET, keep BOOT held.
  4. The port is Maskrom 2207:110c or Loader. After reset it becomes ADB 2207:0006.
Package

Install

Writes loader, env, idblock, U-Boot, boot FIT, userdata, oem, rootfs, then the overlay over ADB.

python tools/cv_ego_flash.py --prebuilt

Rebuild the Ego boot FIT first (Wi-Fi + RV-3028 DTB):

python tools/cv_ego_flash.py --rebuild

Offline tool: select CameVision Ego, click Install. Release BOOT when the board starts.

Where the images live

The full Maskrom set is in restore/release-0.2-20260902/ on this repository: loader, env, idblock, U-Boot, boot FIT, userdata, oem, and rootfs. Clone with Git LFS so the large images download. The offline tool GitHub update and Package file buttons land in restore/updates/current/.

Boot FIT source: device-tree/rv1126b-camevision-ego.dts. Overlay source: restore/release-0.2-20260902/overlay/ and the copies under tools/.

Do not

  • Flash Aura or any other product's boot / oem / rootfs.
  • Switch USB to a UVC webcam gadget.
  • Skip Maskrom on an empty board.
