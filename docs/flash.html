Maskrom · empty board or already flashed

Flash

Hold BOOT, tap RESET, write every partition, then the overlay. USB stays ADB.

The demonstration tool (flash, live page, calibration) is in English.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Install the USB driver (Windows: host/DriverAssitant_v5.14. Linux: host/linux/99-camevision-rockusb.rules).
  3. Hold BOOT, tap RESET, keep BOOT held.
  4. The port is Maskrom 2207:110c or Loader. After reset it becomes ADB 2207:0006.
Package

Install

Writes loader, env, idblock, U-Boot, the selected model's boot FIT, userdata, oem, rootfs, then that overlay over ADB.

python tools/cv_ego_flash.py --prebuilt --package camevision-ego
python tools/cv_ego_flash.py --prebuilt --package camevision-ego-am

SC233HGS rebuild (Wi-Fi + RV-3028 DTB):

python tools/cv_ego_flash.py --rebuild --package camevision-ego

Release BOOT when the board starts. Shop sensors: SC233HGS, OG02C10, MIRA220, AR0235 (colour / mono), OX05B1S, Kaimou GS2.3. The two Maskrom kits in this tree are SC233HGS and AM / MIRA220.

ADB

Open

python tools/cv_ego_page.py

Forwards the on-board stereo page and IMU HUD, then opens a browser.

python tools/cv_ego_autostart.py --install
python tools/cv_ego_diag.py

Where the images live

Two Maskrom kits stay separate. SC233HGS is restore/release-0.2-20260902/ (SENSOR=SC233HGS, boot camevision_boot_ego.img). AM / MIRA220 is restore/release-2.0-am-mira220-20261009/ (SENSOR=MIRA220, boot camevision_boot_ego_am.img). Clone with Git LFS so the large images download. Frozen SC233HGS tree: device-tree/rv1126b-camevision-ego-sc233hgs.dts. AM DTS: device-tree/rv1126b-camevision-ego.dts.

Boot FIT source: device-tree/rv1126b-camevision-ego.dts. Overlay source: restore/release-0.2-20260902/overlay/ and the copies under tools/.

Overlay

After ADB is up, the product is the overlay. Board already flashed: skip Maskrom, run the deploy for that sensor.

python tools/cv_ego_overlay_deploy.py
python tools/cv_ego_overlay_deploy_am.py
