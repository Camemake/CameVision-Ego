CameVision EGO

Dual global-shutter AI stereo camera. Two hardware-synchronised 2.3 MP cameras, one IMU per eye, on-board stereo, depth and calibration. The host only deploys over USB and opens a browser.

What this software does

  • Live stereo page at http://127.0.0.1:8081/
  • Checkerboard calibration at /cal
  • IMU HUD at http://127.0.0.1:8083/ (also /imu)
  • Hardware frame sync so both eyes expose together
  • 50 Hz lighting lock with 12.5 fps trigger and 20 ms exposure steps
  • On-board block matcher, 640×400 depth grid, jet heatmap
  • Display: left pane is CAM1 / IMU1, right pane is CAM0 / IMU0

The host does not compute depth. USB stays the Camemake developer gadget. Do not switch the board to a webcam profile. Do not flash a non-CameVision image.

Quick start

  1. Power the CameVision EGO and connect USB-C to the PC.
  2. From the repository:
python tools/cv_ego_stereo_start.py
python tools/cv_ego_autostart.py --install

Open http://127.0.0.1:8081/. --install adds a Windows logon helper so plugging the camera deploys the overlay, starts the page service, restores USB port forwards, and opens the live view.
