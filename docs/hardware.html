CameVision Ego V1.I1

Hardware

Two global-shutter imagers at 1920×1200, four MIPI lanes per eye, and one IMU beside each camera. Full board notes live in EGO.md.

Camera map

EyeCSIControlPower-downSyncTriggerIMU
CAM0CSI RX0, 4-laneI2C3 @0x30GPIO4_A3GPIO4_A1 → FSYNCGPIO6_C2 → EFSYNCSPI0
CAM1CSI RX1, 4-laneI2C-GPIO @0x30GPIO4_A2GPIO4_A0 → FSYNCGPIO6_C3 → EFSYNCSPI1

CAM1 I2C SCL/SDA are swapped on the PCB versus the SoC I2C4 functions, so that eye is bit-banged. CSI RX1 uses the 4-lane PHY on that port.

Trigger mode is continuous on both sensors. Slave-mode HDR bits stay off so the 3A stack still owns exposure. Trigger rate is 12.5 fps; programmed VTS remains 15. Do not reuse CAM1 power-down or I2C pins as sync outputs.

Fitted parts

  • Memory: 1 GB DDR (the schematic 512 MB label is wrong)
  • Both IMUs are the same part
  • eMMC: BWCTAK611G16G
  • USB-C with battery pads and charger path
  • Wi-Fi 6 + BLE
